# Snapshot Presigner

`snapshot-presigner` validates image snapshot upload requests and returns a presigned S3 PUT URL. It never accepts image bytes and never makes uploaded S3 objects public.

The presigned URL is generated by this Lambda using its IAM role credentials. S3 does not proactively issue the URL; S3 later validates the signed PUT request and expiration when the edge uploader uses the URL.

Required request fields:

```json
{
  "factory_id": "factory-a",
  "node_id": "worker2",
  "filename": "260608094235_event_FALLEN.jpg",
  "content_type": "image/jpeg",
  "size_bytes": 60345,
  "sha256": "hex-encoded-sha256",
  "source_timestamp": "2026-06-08T09:42:35Z",
  "event_type": "FALLEN"
}
```

The S3 key is generated by the Lambda:

```text
image_snapshot/factory_id={factory_id}/yyyy={YYYY}/mm={MM}/dd={DD}/hh={HH}/{filename}
```

## Environment

| Environment variable | Default |
| --- | --- |
| `S3_BUCKET_NAME` | `aegis-bucket-data` |
| `ALLOWED_FACTORY_IDS` | `factory-a` |
| `MAX_FILE_BYTES` | `5242880` |
| `PRESIGN_EXPIRES_IN_SECONDS` | `300` |
| `PRESIGN_SHARED_TOKEN` | empty, auth disabled |

When `PRESIGN_SHARED_TOKEN` is set, callers must send `Authorization: Bearer <token>`.

## Deployed Factory-A MVP

As of 2026-06-08, factory-a uses:

```text
API Gateway endpoint: https://pp604cwuk8.execute-api.ap-south-1.amazonaws.com/image-snapshot/presign
Lambda: AEGIS-Lambda-SnapshotPresigner
Allowed factories: factory-a
Max file size: 5242880 bytes
URL expiry: 300 seconds
Auth token: disabled because PRESIGN_SHARED_TOKEN is empty
```

The Lambda role is allowed to create PUT signatures only for:

```text
s3://aegis-bucket-data/image_snapshot/*
```
